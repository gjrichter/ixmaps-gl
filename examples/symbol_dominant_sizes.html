SYMBOL · CATEGORICAL DOMINANT · size flags The same CHART|SYMBOL|AGGREGATE|SUM|DOPACITYMAX|CATEGORICAL|CENTER|DOMINANT theme four times: GRIDSIZE (circles), GRIDSIZE (hexagons), AUTOSIZE and no size flag. The size flag changes only the symbol size: in every row a cell shows its dominant category (the biggest part above dominantfilter "min"; without one, every category), in its class color, its fill faded by DOPACITYMAX, its outline not. (Each row lies on its own part of the aggregation grid, so the rows' cells differ.)
