ixmaps-engine — chart type & classification examples

Small, isolated demos of each base symbol type and coloring/classification method implemented so far, all against the real AREU (ISTAT road-accident) dataset.

Base symbol types

DOT · CATEGORICAL Fixed-size dot per record, no clustering, colored by exact-match category (NATURA_INC). BUBBLE (CHART|SYMBOL) · CATEGORICAL Full pipeline: value-scaled size, clustering, multi-bubble grouping, glow, VALUES labels.

Numeric range/class coloring (partsA)

Same FERITI field, three classification methods — compare how differently each splits the same skewed data.

DOT · equal-interval Default classification on a fixed-size dot — no CATEGORICAL, no QUANTILE/NATURAL flag. BUBBLE · equal-interval (default) 5 equal-WIDTH buckets across the data's min-max. Most bubbles land in the lowest bucket. BUBBLE · QUANTILE 5 equal-COUNT buckets. Several collapse to the same range on this skewed data — a real quirk, not a bug. BUBBLE · NATURAL (Jenks) Finds actual gaps in the data. Visibly better color discrimination than the other two methods here.

Polygon fill (CHOROPLETH)

CHOROPLETH · QUANTILE Polygon fill classed by a bound numeric value. Geometry borrowed from a same-named FEATURE base layer, joined to a separate CSV via binding.lookup — ~7900 Italian comuni. CHOROPLETH · DOMINANT|PERCENTOFMEAN Multi-field (21 piped columns) per-polygon argmax against each field's own national mean, plus the diverging N-step ["N",cc1,cc2,"3colors",cc3] colorscheme sweep. CHOROPLETH · DOMINANT (no PERCENTOFMEAN) Same 21 piped fields, but classed by whichever field simply has the highest raw value per record — no cross-record mean comparison. CHOROPLETH · DOMINANT|DEVIATION Winning band is the highest z-score — (value-mean)/stddev — above zero, weighing deviation against each band's own natural spread. CHOROPLETH · COMPOSECOLOR|SUBTRACTIVE No single winner — every field's class color blends into one, weighted by value, paint-style (subtractive) mixing.
